03 · Where to run the agency

Keep Vercel. Stop using ChatGPT as the office.

GitHub + Vercel is the right place to host sites. It is the wrong place to manage clients. ChatGPT Pro is a thinking partner. It is not a CRM, not a file system, and not a deployment tool. Mixing ten clients in one chat is how mistakes ship.

Stop doing this

Founder workstation (breaks at 5+ clients)

  • Ask ChatGPT to rewrite a page, copy the code, paste into GitHub, hope Vercel deploys.
  • Keep client facts in chat memory (“the clinic in Dwarka wants Saturday slots”).
  • Give clients “we’ll update it tonight” with no status they can see.
  • Rebuild the same WhatsApp flow from scratch every time.
  • Be the only person who knows how anything is hosted.
Do this instead

Three rooms. AI in each. You approve.

  • Command center — one board per client: status, logins, knowledge, tasks.
  • Build room — AI edits the site from English instructions; you preview and approve.
  • Runtime room — WhatsApp + CRM + n8n templates that already exist; you fill a form, not a chat.

04 · Productized delivery

Six n8n templates. Not a new invention each client.

1. Enquiry → CRM

WhatsApp / form / IG → create/update contact → notify owner.

2. Qualify → book

Approved questions → slot offer → calendar / staff task.

3. No-show / nurture

If no reply in X hours, send utility template, then email.

4. Review ask

After “completed” status + delay → Google review link → log sentiment.

5. Weekly leak report

Counts to WhatsApp for the owner every Monday 9:00.

6. Change request

Portal form → Notion task → you (or Cursor) execute → mark done.

05 · Execution roadmap

Move the office first. Then productize. Then upsell.

1

This week — freeze the chaos

Create a Notion database: Client, Niche, Stage, BSP, Site URL, Knowledge page. Move every live client out of ChatGPT into one row. ChatGPT chats get archived after you copy facts into Notion. Do not start new client work in ChatGPT threads.

2

Next — client portal + intake

Duplicate one Notion “Client OS” template per account. Share it. Add a Tally/Fillout intake that writes to Notion. Send the portal link in the kickoff WhatsApp. This is the flawless experience: visibility without you typing updates.

3

Then — stop pasting code

For webwisedigital.net, only Cursor Cloud Agents may change the repo. For new client sites, pick Framer/Webflow unless the client needs the exact Webwise Smart Site kit. ChatGPT writes copy into Notion; the builder tool publishes.

4

Then — lock the 14-day machine

Days 1–2 intake and knowledge vault. Days 3–7 Smart Site + WhatsApp rules. Days 8–10 CRM + the six templates. Days 11–12 review flow. Days 13–14 live test and training video. Same calendar for every niche.

5

Then — sell from the stack, not from tools

Proposal language: Core System (01–05) as the default. Upsells only after go-live, except Voice for clinics that live on the phone. Never quote “Wati setup.” Quote “WhatsApp engine inside the Webwise system.”

6

Then — hire AI, then a human

A VA who only updates Notion and submits change requests is enough. They do not need to know Vercel. Cursor / Framer / n8n templates do the technical work. You stay on strategy calls and consultancy retainers.
